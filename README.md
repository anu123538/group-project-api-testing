## 🚀 How to Use (Getting Started)

1. Download the `group_project_v2.postman_collection.json` file from this repository.
2. Open your Postman App and click the **Import** button.
3. Select the downloaded JSON file to import the collection.
4. Ensure your Local Server (XAMPP/WAMP) is running.
5. Click **Send** on the requests to test the API responses.
